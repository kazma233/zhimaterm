# ADR-023:右键上下文菜单

状态:已接受(2026-10)

## 背景

分屏与搜索此前只有键位入口(ADR-014/015),可发现性差;SFTP 对选中项的操作
(下载/重命名/删除)挂在底部操作条,离条目远,还要「先选中再找按钮」。右键
弹出上下文菜单是文件管理器与终端的通行习惯,两类问题一并解决。

## 决策

### 终端格:右键 = 本地菜单,不再转发前台程序

- 右键弹出三项:水平拆分(左右并排,即 ⌘D 的 SplitRight)、垂直拆分(上下
  堆叠,即 ⌘⇧D 的 SplitDown)、搜索(即 ⌘F 的 OpenSearch)。动作走既有
  action 派发与视图方法,菜单只是另一条入口,不新增语义。
- 右键从鼠标上报里整体让位:按下、松开、按住移动都不再发给前台程序
  (xterm 上报要求按下/松开成对,不能只拦一半)。全屏程序(vim/mc)拿不到
  右键,与 Windows Terminal、iTerm2 的默认行为一致。
- 右键同时把树焦点切到被点的格(格命中从左键扩展到右键):分割动作从焦点格
  发起(ADR-014),多格时「在哪右键就拆哪格」,新格会话类型也因此跟随被点的格。
- Esc 关菜单;点击菜单外(遮罩覆盖整个格区域,含 SFTP 面板)也关。

### SFTP:条目右键菜单取代底部操作条

- 右键条目先选中再弹菜单:下载/重命名/删除,动作与确认链路(覆盖、递归删除、
  重命名不覆盖,ADR-002)原样复用,只是入口变了。
- 底部操作条整条移除:上传文件/上传目录/新建目录不依赖选中项,并入顶栏
  (SFTP 标题旁,窄面板放不下时换行);刷新入口只在导航栏右缘一处,顶栏不再
  重复放第二个刷新。

### 菜单组件

- `ui::menu`:遮罩(任意键点击收起)+ 指针处定位的浮层,条目回调回到调用方
  实体(与模态装配同一模式,ADR-007)。位置按所在容器的 bounds 夹取,右缘/
  下缘放不下就向内收,不越出容器。
- SFTP 菜单只盖面板区域:面板浮在终端之上,面板内弹层不遮终端是既有口径
  (对话框同款)。

## 后果

- `terminal_view` 持有菜单锚点与终端容器 bounds;`panes::render_area` 的格
  命中扩展到右键(只挪树焦点,不开菜单——菜单归视图)。
- 鼠标上报协议少一个按键,是显式取舍;依赖右键的前台程序属于罕见用法。
- 键位仍是唯一带「语义」的入口,菜单不显示键位提示,快捷键参考表(侧栏 ?)
  不变。
