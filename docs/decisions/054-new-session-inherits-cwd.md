# ADR-054：新开本地会话继承发起格的工作目录

状态：已接受（2026-11-11）。

## 背景

新开本地会话（⌘T / 侧栏「本地」、分屏新格）的初始目录取设置里的默认值
（ADR-036），与用户实际所在位置脱节——「在当前目录再开一条线」是开新控制台的
主要意图，落点却常常是 home 或固定目录。分屏新格沿用的还是发起格**构造时**的
目录（`split_target` 克隆 `local_shell`），发起格里 cd 过之后新格也不跟随。

ADR-053 之后工作目录已是侧栏会话身份，每个本地格都有实时 cwd（ADR-039 采样
链路），继承它不需要新机制。

## 决策

### 1. 新开本地会话落在新开那一刻焦点格的目录

初始目录 = 发起那一刻焦点控制台的 cwd；拿不到时回落 ADR-036 既有链
（设置默认工作目录 → home）。覆盖全部三个新开本地会话的入口：

- **⌘T / 侧栏「本地」入口**：焦点格的 cwd；
- **分屏新格（ADR-014）**：发起格的 cwd——修订原「沿用构造时目录」的语义，
  会话类型跟随原格不变；
- **关掉最后一个标签的自动补开**：刚关掉那个标签焦点格的 cwd（移除前采集）。

Shell 程序选择不变（设置的默认 Shell，ADR-036）。SSH 新格与 WSL 入口不受
影响：SSH 无 cwd 采样、WSL 的目录在子系统里宿主侧采集不到（既有边界），
由它们发起时回落设置默认；应用启动首开（还没有任何格）同样回落。

### 2. 继承优先于设置默认；失效不静默回退

- 设置的「默认工作目录」从「新会话落点」变为「无焦点目录时的回落」，
  留空 = home 的语义不变。
- 继承到的目录在启动前被删（外部 rm）由 PTY 启动失败显式报错（ADR-036
  决策 5 同口径，不静默换目录）。

### 3. 实现落点

- `LocalShell` 增加 `cwd()` 与 `with_cwd()`：Default/Program 的目录可读可换，
  Wsl 无宿主侧目录、原样返回。
- `TerminalView::split_target()` 以发起格当前 cwd 覆盖构造目录（cwd 尚未
  上报的格保留构造目录）；外壳开本地会话时以焦点格 cwd 盖过设置默认
  （`close_session` 在移除标签前采集）。

## 后果

- 新开本地会话与分屏落在用户当前目录；设置默认工作目录只在无焦点目录时生效。
- 修订 ADR-036 决策 2（「本地」入口用设置默认值 → 目录继承优先）与
  ADR-014 的新格目录语义。
- 工作区恢复不受影响（ADR-039 按叶恢复各自的目录链）。
- UI 编排不设单测（仓库惯例），手工验收项见 `docs/context/manual-acceptance.md`。
