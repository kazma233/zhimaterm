# ADR-037：窗口几何与本地布局持久化

状态：已接受（2026-10-21）。覆盖 ADR-014「布局不持久化」的初版取舍。

## 背景

requirements §7 要求持久化标签布局与窗口状态，一直未实现；ADR-014 当初为控制
范围写明「布局不持久化」。2026-10-21 批次补齐，并按用户决策把范围收窄到
**只持久化本地格**：SSH 标签与格不恢复，重启后必须显式重新连接。

## 决策

1. **独立文件 `workspace.json`**，与 `settings.json` 分开：布局与窗口几何是
   高频自动写入的会话态，不是用户显式偏好。写入走临时文件 + rename，与设置、
   保存连接同一套原子写模式。
2. **只记本地格**（`Local` / `Wsl { distro }`）。保存时按格裁剪：SSH 格被剔除，
   兄弟子树顶位（该分割的比例失去意义，随结构一起消失）；全 SSH 的标签整个
   不出现。恢复时每个本地格**自动启动全新 shell**（Shell 用当前设置；工作目录
   与回滚由 ADR-039/040 恢复；WSL 用原发行版），不恢复旧进程或运行中程序——
   「不自动恢复连接」的边界只对 SSH 生效，本地格由布局恢复动作本身承担显式启动。
3. **恢复内容**：窗口几何（`Windowed` / `Maximized` / `Fullscreen` 三态，文件里
   自存为简单结构）、标签顺序、每标签的分屏树（方向 + 比例）、活动标签、
   累计会话编号（避免新格重号）。焦点落在恢复标签的树序第一格。
   > 2026-10-22 修订（用户拍板）：不再保存/恢复最大化与全屏，一律以窗口态
   > 打开。Aero Snap 拖顶边、双击标题栏都容易无意识最大化，退出后固化进
   > 文件，重开表现为「随机全屏」。保存侧把三种状态压成窗口态（bounds 用
   > gpui 的还原矩形，最大化时 `rcNormalPosition` 仍保有还原尺寸，重开大小
   > 不变）；恢复侧旧文件的 maximized/fullscreen 同样按窗口态处理并走屏内
   > 检查。枚举变体仅为读取旧文件保留。
4. **窗口几何回退**：`Windowed` 的保存矩形必须与当前至少一个显示器相交，
   否则回退默认居中（外接屏拔掉后不能恢复到看不见的位置）。显示器枚举用
   gpui 的公开 `App::displays()`。
5. **写入时机**：布局变化（开/关标签、分屏、关格、切标签、拖拽排序、拖比例松手）
   经 `layout_changed` 收口，本轮更新末合并写一次——连环变更（批量关格、恢复
   逐标签重建）只写一份；窗口几何变化防抖 500 ms 写（拖拽缩放期间只记录代际，
   停下后写最后一次）；`on_app_quit` 兜底直写一次（用缓存的最近几何，退出回调
   拿不到窗口句柄）。
6. **失败语义**：文件不存在 = 首次启动，不报错；解析失败或版本高于当前支持
   版本 = 回退空布局并在侧栏顶部报错，**不覆盖原文件**（下一次保存会覆盖——
   与设置同一纪律：读不出来时不写）。保存失败同样在侧栏报错，不打断操作。

## 实现结构

- `panes::LayoutSpec`：布局树的公开只读投影（叶/分割），`PaneTree::structure()`
  与 `PaneTree::from_spec()` 负责往返；重建时比例夹回 [0.15, 0.85]、格数按
  每标签上限校验、分割标识按先序重分配。
- `workspace` 模块：serde 结构、裁剪（`SavedNode::from_layout`）、重建
  （`SavedNode::to_layout`）、窗口几何换算与文件读写；裁剪与回退是纯函数，单测覆盖。
- `TerminalView::workspace_leaf()` 是格 → 持久化形态的唯一投影（SSH 返回 None）。
- `main` 在建窗前读工作区并决定窗口 bounds；应用恢复标签后注册
  `observe_window_bounds` 与 `on_app_quit`。

## 后果

- 重启后看不到 SSH 标签：这是决策而非缺陷，侧栏不提示「有未恢复的会话」。
- 本地格的新 shell 从上次工作目录启动，并带回最近回滚（ADR-039/040 覆盖了
  本节初版「从 home/设置目录重新开始」的结论）。
- 布局文件损坏时用户会看到侧栏错误；修好或删除文件后下一次写入恢复。

## 验证

- `cargo test workspace::`：混合标签裁剪（SSH 格剔除、兄弟顶位、全 SSH 消失）、
  保存→读取往返、版本过新拒绝、屏外窗口回退。
- `cargo test views::panes::`：LayoutSpec 往返、比例夹取、焦点与格序。
- 手工（2026-10-21 已验收）：开本地分屏 + 一个 SSH 标签 → 退出 → 重启：窗口几何、本地标签与
  分屏比例回来且本地 shell 自动启动，SSH 标签不出现。
