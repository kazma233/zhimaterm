# ADR-058: 格右上角动作图标组

状态:已接受(2026-11-17)

## 背景

拆分与搜索此前只有两条入口:键位(⌘D/⌘⇧D/⌘F,ADR-014/015)与右键菜单
(ADR-023)。菜单解决了可发现性,但每次都要「右键 → 再点一项」,高频动作
离手远。同时格右上角已经挤了三个同位浮层:「✕ 关闭此格」按钮(top 6/right 8)、
搜索条(top 8/right 8,ADR-015 2026-11-16 修订)与 SSH 转发状态卡片
(top 8/right 8,宽 340)——同一坐标各自为政,重叠时全靠渲染顺序碰运气。

## 决策

### 每格右上角常驻一行图标按钮

- 内容:`[左右分屏] [上下分屏] [搜索]`,多格时末位追加 `[✕ 关闭]`。单格
  也显示——单格恰恰是最需要拆分入口的时刻;关闭仍只在多格时出现(单格
  关闭 = 关标签,走侧栏与 ⌘W,不进布局层的按钮)。
- 图标用内嵌单色 SVG(`views::icons` 既有机制,ADR-057 修订),悬停 tooltip
  用 `ui::tooltip`;图标 + tooltip 借机统一措辞:按钮与 tooltip 一律叫
  「左右分屏 / 上下分屏」,废弃右键菜单里「水平拆分/垂直拆分」的歧义叫法
  (菜单里的「水平拆分」实际是左右并排,键位表却叫「左右分屏」)。
- 每标签格数到上限(8,ADR-014)时两个拆分钮置灰禁用(不可点、箭头光标、
  tooltip 提示「最多 8 格」)——右键菜单表达不了禁用态,这是按钮的净增益。
- 按钮点击语义走 ADR-024(松开在按钮内才触发);整行 `.occlude()`,行内
  空隙的点击也不落到终端网格。

### 归属:panes(布局树所有者)

- 行渲染与点击装配都在 `panes::render_area`,与原「关闭此格」同位——树焦点、
  格数上限、关闭回调本来就在这里,不新开所有权。
- 拆分点击 = 先把树焦点切到本格,再派发既有 `SplitRight`/`SplitDown` action
  (应用根 `on_action` → `split_focused`)。派发延帧执行而树焦点同步生效,
  「在哪点就拆哪格」与右键菜单语义一致(ADR-014/023);新格会话类型也因此
  跟随被点的格(ADR-054)。
- 搜索点击 = 直调本格视图的 `open_search`,不走 action 派发——action 沿
  焦点路径派发,焦点在别的格时会开错格;直调天然「点哪搜哪」。
- 关闭沿用既有 `AreaActions::close_pane` 回调,语义不变。

### 右上角浮层的避让规则

- 动作行几何常量(`PANE_ACTION_ROW_TOP/HEIGHT`)由 panes 公开,搜索条与
  转发状态卡片统一下移到「行底 + 间距」处(`OVERLAY_TOP_BELOW_ACTION_ROW`):
  两个浮层同一位移、同一条规则,不再各自记 top 值。动作行常驻不移位。

### 右键菜单只删搜索项

- 终端右键菜单移除「搜索」项与分隔线,保留两个拆分项——拆分项留作后续
  扩展(如「向选中拆分」类条目)的载体,搜索已有更近的按钮入口。右键仍
  不转发前台程序(ADR-023 核心语义不变,见其修订段)。

## 修订

- ADR-015:搜索条位置从「右上角锚定」改为「动作行下方」,见 ADR-015 修订段。
- ADR-023:终端右键菜单条目变化,见 ADR-023 修订段。

## 后果

- `panes.rs` 新增行渲染与几何常量;`terminal_view.rs` 的搜索条/转发卡片
  top 值改引常量;右键菜单条目清单缩短。
- 新增 4 个 SVG(`split_side`/`split_stack`/`search`/`close`),遵循
  `icons.rs` 的构图契约(16×16 viewBox、填充路径、顶满四边)。
- 快捷键不变,仍是唯一带「语义」的入口(菜单与按钮都只是另一条入口,
  不新增动作语义)。
- 动作行悬浮在网格上方:满屏程序(vim 等)首行右缘若有内容会被行遮住;
  与原「关闭此格」同位的既有取舍一致,行可 `.occlude()` 点击不落网格。

## 修订（2026-11-25：动作行退役）

本 ADR 的动作图标行整体作废（ADR-063）：拆分、搜索、关闭只保留键位入口，
`panes` 不再渲染每格动作行，动作行几何常量与可用态判定一并删除。
搜索条与转发状态卡片回到右上角 `top/right = 8px`，不再向下避让；
「右键菜单只删搜索项」一节随终端右键菜单整条退役一并失效。
