# ADR-041：侧栏底部动作行与主题色板入口

状态：已采纳（2026-10-21）

## 背景

会话入口此前分散在两处：ADR-021 把「本地」「WSL」放在侧栏顶栏「会话」标题旁，
ADR-022 把「SSH 会话」和主题入口放在底部 footer。Windows 上三个入口分居顶栏与
底栏，位置不统一；主题入口又用整行显示当前主题名，长名字（如
`GitHub Light High Contrast`）占据底部大部分宽度。

本次要求：

- 会话入口统一放到侧栏会话列表下方的空区；
- 底部只允许一行，不能再叠第二行；
- 主题入口不显示主题名，只显示三点色板。

侧栏宽度可拖 140–420，界面字号按 rem 整体缩放，布局必须在最窄宽度下仍可用。

## 决策

### 1. 底部单行动作行

列表之后、侧栏底缘之上固定一行：

```
本地 | WSL | SSH | [色板]
```

- 顺序固定为本地、WSL、SSH；WSL 仅 Windows 编译目标存在，且启动时零发行版
  隐藏（沿用 ADR-021 的可见性口径），行自动变为两段。
- 三个入口等分剩余宽度，短标签 11px、居中；段间用 `vertical_divider` 分组，
  hover 整段 `bg_hover`，点击语义仍走 `panel::clickable`。
- 标签用「本地 / WSL / SSH」而不是「SSH 会话」：侧栏最窄 140px 时内宽 124px，
  色板与分隔线占约 30px，三段各约 30px，完整「SSH 会话」放不下；短标签在
  最窄宽度和默认 300px 下都不截断。SSH 连接弹窗标题仍是「SSH 会话」。
- 动作行与主题色板共用这一行，不再叠加第二行。整块高度约 26–28px，不高于
  原 footer（约 30px）。

### 2. 设置入口移到顶栏

⚙ 从底部 footer 移到顶栏右侧、`?` 左侧，与 `?` 同字号、同自然行盒。顶栏仍是
「会话」标题 + 右侧全局入口，不增加行高。底部动作行因此只承载会话创建，
不混入应用设置。

### 3. 主题入口只留三点色板

- 入口改为 24×14 的主题色板：主题背景色块内叠红/绿/蓝三个 4px 圆点，与
  主题下拉项共用同一套 `swatch`。
- 不显示主题名，也不使用 `◐` 占位符；入口宽度固定，不再随主题名长短变化。
- 点击仍从色板正上方展开主题下拉；下拉项保留「色板 + 主题名 + 当前项标记」，
  点击一项立即切换且保持展开（ADR-022 的连续比对交互不变）。
- 当前主题名只在展开的下拉里可见；下拉的当前项标记（底色 + `●`）是唯一的
  当前状态提示。

## 后果

- 取代 ADR-021「入口与交互」中的位置约定和 ADR-022 §6 的主题入口形态；
  WSL 的发行版选择模态、ADR-036 的「本地入口一键开」均不变。
- 侧栏最窄 140px 时动作段约 30px/段，短标签刚好放下；界面字号放大后极端窄宽
  下标签可能被裁剪，属于可接受的降级。
- UI 接线不设单测（与仓库现状一致）；布局与平台分叉需人工验收，已记入
  `docs/context/todo.md` 的待人工验收。
- 需求规格 §3.2 与 README 的界面骨架/主题描述同步更新。
