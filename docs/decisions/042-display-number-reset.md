# ADR-042：会话显示编号在空列表时重置

状态：已采纳（2026-10-21）

## 背景

侧栏没有前台标题时显示 `会话 N`。这个 N 原先直接复用持久化编号（ADR-039 的
回滚文件键）。持久化编号在进程内只增不复用，所以关掉最后一个标签后自动补开的
新会话仍然继续递增（16、17……），不会回到 1。

不能直接把持久化编号清零：回滚文件以 `<number>.log` 命名，关掉的旧会话 worker
会在退出时异步写回滚；新会话复用同一个编号会读到旧内容，或多个写入方互相覆盖。

## 决策

### 1. 显示编号与持久化标识分离

- `created` 与工作区叶的 `number` 是持久化标识：只增不复用，继续作为回滚文件
  键与工作区叶标识（ADR-039 不变）。
- `label_created` 与视图的 `display_number` 只决定侧栏 `会话 N` 文案，不参与
  任何文件命名。

### 2. 运行时重置

`close_session` 删掉最后一个标签后，先把 `label_created` 归零，再补开新本地
会话。因此新会话总是显示「会话 1」，之后新建的依次是 2、3……

关掉非最后一个标签不会重排剩余编号，保持原有「关闭其他标签不会跳号」的行为。

### 3. 持久化显示编号

工作区 v2 增加：

- `Workspace.label_created`：显示编号的累计计数；
- `SavedNode::Local/Wsl.label_number`：每个格恢复后应显示的编号。

两处都带 `serde(default)`：旧文件缺字段时回退到持久化编号，不影响读取。
有可恢复标签时显示编号从工作区读回；标签列表为空、没有可恢复标签时，启动补开
的会话也从 1 开始。

### 4. Windows 标题优先级不变

有前台程序设置的 OSC 0/2 标题时仍显示标题（包括 PowerShell 的路径标题），
没有标题才回退到 `会话 N`。

## 后果

- 关掉最后一个会话后，新会话显示「会话 1」，侧栏不会随运行时长无限增大。
- 持久化编号继续递增，回滚文件键始终唯一，旧 worker 的异步写回不会污染新会话。
- 重启后：有恢复标签则沿用保存的显示编号；没有恢复标签则从 1 开始。
- UI 编排不设单测（与仓库现状一致），手工验收：开 3 个会话 → 关闭第 2 个
  （剩余编号不重排）→ 关闭最后一个 → 新会话应为「会话 1」→ 再开一个应为
  「会话 2」。
- 工作区旧文件仍可读；旧构建读取新文件时忽略新增字段，回退到旧编号行为。
