# ADR-047：侧栏会话行手动重命名

状态：已接受（2026-10-27）。

## 背景

侧栏会话行的标题只有一个来源：聚焦格里前台程序设置的 OSC 0/2 标题，没有时
用显示编号 `会话 N`（ADR-042）。连接多了之后「会话 3」「zsh」「vim x.rs」这类
标题分不出哪一行是哪台机器、哪条工作线——mobaxterm 差距清单 P2 的「会话手动
重命名」。本次只做重命名，不做分组。

## 决策

### 1. 名字挂在标签，不挂在格

- `Tab.name: Option<String>`：侧栏一行对应一个标签；分屏标签里切焦点格时
  自动标题会跟着聚焦格跳，用户起的名字不能跟着跳。
- 标题优先级：**用户起的名字 > 聚焦格 OSC 标题 > `会话 N`**。只影响侧栏行
  （含拖拽幻影）；窗口标题继续跟聚焦格的 OSC 标题走——侧栏回答「这是哪条
  线」，窗口标题回答「里面在跑什么」。
- 空名即「不起名」：输入 trim 后为空就把 `name` 清回 None，回到自动标题；
  不把空字符串或一串空格固化成名字（`normalize_session_name`，有单测）。

### 2. 入口是会话行右键菜单（ADR-023）

- 右键会话行在指针处弹菜单，当前只有「重命名」一项。**不切换活动标签**：
  右键是「对这一行做点什么」，不是「切过去」（浏览器/编辑器标签页同款）。
- 菜单复用 `ui::menu`，遮罩与浮层挂在**应用根部**、盖住全窗（含终端区）：
  遮罩 `occlude` + 三键按下都只收菜单并 `stop_propagation`，浮层自身截停
  左键按下——点哪里都不会落到会话行（切换/起拖拽）或终端网格。
- Esc 收菜单走应用根的 `capture_key_down`（仓库首次使用捕获阶段）：菜单不持有
  焦点，焦点仍在终端；终端的冒泡监听把按键写进 PTY 后**不截停传播**，冒泡阶段
  再拦已经晚了。捕获阶段截住并 `stop_propagation`，gpui 不再进入冒泡阶段。
  其余按键照常进终端（与终端格菜单「Esc 只收菜单，其余按键照常」同口径）。
- 菜单与主题下拉同为锚定浮层（ADR-027）：互相打开即收起对方；任何层入浮层栈
  （`overlay_open`）也收起它。菜单按标签下标记目标，列表一变（`layout_changed`）
  就收起，避免指错行。

### 3. 输入走通用 Dialog 的 prompt 形态（ADR-044 §4 的首个消费方）

- `Dialog::prompt`：标题「重命名会话」，占位显示当前自动标题（留空确认就回到
  它），预填当前起过的名字（没起过为空，不预填自动标题——否则不改直接确认会
  把「会话 3」固化成名字），确认按钮「重命名」，Enter 确认、Esc/遮罩取消。
- 打开后直接聚焦输入框：单字段名称弹窗「输入就是目的」，是 ADR-043 §4 保留
  的既有口径（SFTP 新建/重命名同款）。
- 外壳实体的方法已在自身 update 里，不能再走 `dialog::open` 的全局通道
  （嵌套 update 同一实体会 panic），因此 Dialog 新增 `modal()`：只装成
  `Box<dyn ModalView>`，由 `ZhimaTermApp::overlay_open` 入栈。预填经新增的
  builder `initial_input`。

### 4. 持久化（ADR-037）

- `SavedTab.name: Option<String>`，`#[serde(default)]`，不升 `WORKSPACE_VERSION`：
  旧文件缺字段按「没起名」读；旧构建读新文件忽略未知字段。
- 改名经 `layout_changed` 落盘（与标签顺序同一口径）；名字没变不写。
- 只持久化本地标签的名字——SSH 标签本就不进 workspace.json（ADR-037 决策 2），
  重启后 SSH 标签与它的名字一起消失，这是既有边界不是新口径。

## 后果

- 新能力：右键会话行 → 重命名 → 侧栏显示新名字，重启后本地标签名字保留。
- `TerminalView::label()` 语义不变（仍是「格的自动标题」），标题优先级收在
  `Tab::label`。
- 对话框开着时 ⌘T/⌘W **不响应**（ADR-044 的 2026-10-27 修订）：这两条是
  `Scope::App` 绑定，任何焦点都匹配、且绑定匹配先于裸键派发，`handle_key_down`
  的浮层分支拦不到；落地时发现它们会在对话框底下开/关会话——开会话把焦点抢到
  新格、关会话删掉标签或用关闭确认顶掉重命名框，并让按下标记目标的本对话框
  落到移位后的行。门控在应用根的 `on_action`：浮层栈非空即不执行。
- 单测：`normalize_session_name`、`SavedTab` 带名往返与旧文件兼容、
  `Dialog::initial_input` 预填回传。UI 编排（右键、菜单遮罩、Esc 捕获、
  焦点、落盘时机、弹窗下 ⌘T/⌘W 不响应）按仓库惯例不设单测，手工验收项见
  `docs/context/manual-acceptance.md`。
