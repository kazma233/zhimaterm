# ADR-063：终端右键菜单与格动作行退役

状态：已接受（2026-11-25）

## 背景

拆分、搜索与关闭格此前各有两条鼠标入口：终端右键菜单（ADR-023，2026-11-17
修订后只剩两个拆分项）与每格右上角常驻动作图标行（ADR-058：左右分屏 /
上下分屏 / 搜索，多格时追加关闭）。两条入口都是对键位语义的重复包装，
动作本身早已有完整键位（⌘D/⌘⇧D/⌘F/⌘W）。

常驻动作行悬浮在网格之上，满屏程序（vim 等）右上角的内容会被遮住；右键
菜单则让终端拿不到右键上报。两项都是有持续成本的入口，而它们的可发现性
收益已经由快捷键参考表承担。

## 决策

### 1. 终端右键菜单整条退役

- 删除终端格的右键菜单（条目、遮罩、键盘游标与 `terminal-context-menu`
  浮层）。右键不再有本地语义，回到普通鼠标上报管线：按下、松开、按住移动
  都转发给前台程序；程序未开启鼠标上报时本地不产生动作（选区只认左键，
  中键与右键本地无语义）。
- 右键仍把活动格切到被点的格（树焦点）：右键动作不再依赖焦点，但随后的
  ⌘W/⌘F 必须作用于用户刚点的格，树焦点与 gpui 焦点保持一致。
- 右键不再与 ⌘ 点击链接冲突：链接打开只认左键。

### 2. 格右上角动作行退役

- 删除 `panes` 的动作图标行（左右分屏、上下分屏、搜索、多格时的关闭）与
  其几何常量、可用态判定和单测。拆分、搜索、关闭只保留键位入口：
  ⌘D / ⌘⇧D（非 macOS `Ctrl+Shift+D` / `Ctrl+Shift+Alt+D`）、⌘F
  （`Ctrl+Shift+F`）、⌘W（`Ctrl+Shift+W`，多格时关闭聚焦格；已结束会话
  前台时 Enter 同样关闭聚焦格）。
- 每标签 8 格上限不变，由布局树与 `split_focused` 拒绝超限拆分；不再有
  置灰按钮这一视觉提示。
- 搜索条与转发状态卡片回到右上角 `top/right = 8px`：动作行不存在后不再
  需要向下避让。

### 3. 清理

- 删除四个仅供动作行使用的图标资产（`split_side` / `split_stack` /
  `search` / `close`）与 `views::icons` 常量。
- `ui::menu` 继续服务 SFTP 条目菜单与侧栏会话行重命名，组件本身不改。

## 修订

- ADR-023：终端格「右键 = 本地菜单」一节作废，见其修订段；SFTP 条目右键
  菜单不变。
- ADR-058：动作图标行整体作废，见其修订段。
- ADR-015：搜索条位置回到右上角锚定、按钮入口移除，见其修订段。
- 需求规格：关闭确认的入口清单去掉「格内 ✕」。

## 后果

- 鼠标不再能直接发现拆分/搜索/关闭入口，可发现性交给快捷键参考表；这是
  明确的产品取舍——键盘是唯一带语义的入口，不再维护第二条入口。
- 全屏程序首行右上角不再被常驻按钮遮挡，终端网格恢复完整。
- 右键重新可用于前台程序（开启鼠标上报时），与 xterm/Windows Terminal
  的默认上报语义一致。
- 关闭确认、多格聚焦、搜索条与转发卡片的行为不变，只换了入口与位置。
