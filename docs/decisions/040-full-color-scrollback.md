# ADR-040：本地格回滚的全彩恢复

状态：已接受（2026-10-21）。取代 ADR-039 §C.2「颜色/样式不保留」的取舍；
ADR-039 的其余结论（采集时机、文件位置、容量、失败语义）继续有效。

## 背景

ADR-039 恢复的是纯文本回滚：`cd` 过的目录回来了，旧输出也会滚进历史，但
颜色、粗体、下划线全部丢失，恢复出来是黑白文本。用户要求重启后仍按上次
看到的样子展示。

ADR-039 当时的理由是「保留 ANSI 颜色/属性或序列化屏幕，体积与跨版本脆弱性
不划算」。现在把范围收窄到**按样式 run 转录逻辑行**，既不序列化整个屏幕，
也不在文件里存原始转义序列，体积和兼容性代价可控。

## 决策

1. **转录单位是逻辑行 + 样式 run**，与现有 `tail_transcript` 相同的折行拼接
   口径：物理折行接成一条逻辑行，硬换行才分行；宽字符跳过尾格、保留组合字符；
   默认样式的尾部空格裁掉，带背景色/下划线的尾部空格保留。
2. **颜色存语义值，不存解析后的 RGB**：
   - 默认前景/背景存 `Default`，ANSI 0–15 与 256 色存 `Indexed(n)`。恢复时
     按**当前主题**解析，切换主题会像现存历史一样整体换色。
   - 真彩色（SGR 38/48;2）存 `Rgb`；程序经 OSC 4/10/11 改写过的槽位也按
     `Rgb` 固化——它们不是主题推导出来的，必须保持上次看到的确切颜色。
   - 反相与变暗保留为标志（SGR 7/2），在渲染时按当前主题重新计算；不预先把
     它们解析进 RGB，否则主题切换后恢复的内容会和新输出割裂。
3. **文件格式**：`scrollback/<会话编号>.log` 改为带版本头的 JSONL：
   ```
   #zhimaterm-scrollback v2
   [{"text":"…","foreground":2,"bold":true},…]
   ```
   - 首行是版本头；读到更高/未知版本整份忽略，不按旧语义猜字段。
   - 没有版本头的文件按 ADR-039 的纯文本格式读取（无颜色），老用户历史不丢。
   - **不写裸 ANSI**：颜色在恢复时由结构化数据生成 SGR，手改过的文件也无法
     注入清屏、改标题等控制序列。
   - 颜色用 u32 紧凑编码：0 = 默认、1..=256 = 索引、`0x01RRGGBB` = 真彩色。
   - 仍是临时文件 + rename 原子写；每格最近 1,000 行且不超过 1 MB，超出时
     从最早的行开始丢。损坏的 JSON 行单独跳过，不影响其余历史。
4. **恢复**：逐 run 生成 `ESC[0m` + 属性（SGR 1/2/3/4:1–4:5/7/8/9、38/48/58），
   文本逐字符过滤控制符，逻辑行之间发硬换行，再由终端自动折行。折出的
   `WRAPLINE` 让下一次保存仍能接回一条逻辑行。
   分界行与「一屏减一行换行」的滚入技巧不变；换行数与内容占多少视觉行无关，
   折行不会让恢复内容留在视口或漏进历史。
5. **失败语义**沿用 ADR-039：读失败/版本不兼容静默跳过；写失败保留上一份
   文件并退避重试；备用屏期间不写。

## 备选方案

- **存解析后的 RGB**：实现最简单，但默认背景会固化成旧主题的颜色；用户从
  深色切到浅色主题后，恢复出来的历史是一块块旧底色，和新输出不可读。否决。
- **序列化整个 Grid（alacritty serde）**：按格存储，体积大、跨版本字段语义
  脆弱。否决。
- **直接往 Grid 注入单元格**：历史扩容与负行写入依赖上游内部结构
  （`cursor.template`、`scroll_up` 的旋转细节），依赖升级容易坏。否决。
- **文件里直接存 ANSI 字节流**：恢复简单，但把远端输出产生的转义序列原样
  落盘再回灌，破坏 ADR-039 的注入边界。否决。

## 后果

- 重启后本地格的观感：上次的彩色输出 → 暗色分界行 → 新提示符，新提示符仍在
  原来的目录。
- 索引色随主题变化；真彩色和程序改写过的颜色保持冻结，这是有意为之。
- 旧版纯文本回滚文件第一次被新版本读取时仍是黑白；下一次正常退出写入后升级
  为 v2。
- 第一版不恢复 OSC 8 超链接（颜色与文字属性完整，链接点击能力不保留）。
- 备用屏内容仍不恢复；每格仍受 1,000 行 / 1 MB 上限约束。

## 验证

- `cargo test terminal::transcript_tests`：样式转录、折行拼接、宽字符、默认
  尾部空格裁剪、SGR 恢复后的颜色与粗体、颜色紧凑编码往返。
- `cargo test session::scrollback::`：彩色文件往返、裸转义检查、旧纯文本回退、
  更高版本忽略、坏行跳过。
- `cargo test local_scrollback_is_restored_by_the_next_session`：真实 PTY 输出
  红色 + 真彩色 → 关闭 → 新会话搜回历史，断言红色、粗体与真彩色原样出现。
- 手工（2026-10-21 已验收）：`ls --color`/`git diff` → 退出 → 重启，颜色一致；
  切换主题后历史中的索引色跟随新主题。
