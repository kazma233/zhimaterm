# 功能行为说明

各功能的实际行为与交互细节（使用者视角）。README 只保留产品功能介绍，
本文件承接原先写在 README 里的行为章节；需求口径见 [requirements.md](requirements.md)，
开发与测试内容见 [development.md](development.md)，决策依据见对应 ADR（目录见 [docs/README.md](../README.md)）。

## 性能设计

早期版本一次击键要等约 16 ms、刷屏时整机发卡，实测定位到三个原因，现已按下表改造。
数字来自真实 PTY 的临时诊断（`awk` 持续输出 99 MB + 逐条命令往返），改完即删除：

| 项 | 改造前 | 现在 | 做法 |
|---|---|---|---|
| 空闲命令往返延迟 | 15.6 ms | **9.3 ms**（受 8 ms 帧节拍限制，输入路径本身 <1 ms） | 命令、输出、补帧定时器统一等待，去掉 16 ms 轮询 |
| 刷屏时快照产出 | 3520 帧/秒（≈107% CPU） | **114 帧/秒**（≈5% CPU） | 每轮限时合并输出 + 8 ms 帧节流 + 通道满时保留帧重试 |
| 每帧 UI 元素 | 4375 个（逐格一个 div + 文本子节点） | **约 36 段 run** | 快照按样式合并成 run，行尾默认底色按格裁掉 |
| 格宽来源 | 硬编码 8.6 px | 字体实测 `advance('M')` | run 里一段文本宽度必须与网格同源，否则会逐格漂移 |
| 行高 | 硬编码 19 px | `ceil(ascent − descent)` = 16 px | 字体行框；**descent 在 macOS 上是负值**，写成相加会把行高压到 10 px、行与行重叠 |
| reader → worker 队列 | 无界 `mpsc` | 有界 32 + 阻塞背压 | 刷屏时由 PTY 内核缓冲限流，不再无限堆积内存 |

### 字体与格尺寸

- 等宽字体候选来自「逐家族实测字形步进」：枚举全部已安装字体，量探测字符（`i`/`l`/`W`/`M` 等）的步进是否一致，
  一致才算等宽。不用字体声明的等宽标志（偶尔与事实不符），macOS/Linux/Windows 同一条路径，本机安装的
  Maple Mono、PT Mono 等也能自动出现在设置下拉里。默认挑选按平台常见程度排优先级（macOS 优先 `Menlo`、
  `SF Mono`；Linux 走 `DejaVu Sans Mono` 等；Windows 走 `Cascadia Mono`、`Consolas`），不再写死单一字体——
  写死会导致其他平台静默回退成非等宽字体、整屏错位。
- CJK 与 Emoji 通过 `Font.fallbacks` 显式给出（PingFang SC / Noto Sans CJK SC / Apple Color Emoji 等）。
- 宽字符（CJK/Emoji）在快照里**单独成段**并在两格宽的行内居中绘制：回退字体的字宽未必正好两格，
  与相邻半角格合并会被左对齐后右边留空，中文看起来字距忽大忽小。
- 字体与字号不再常驻显示（顶栏已去掉，见下）；排查显示问题时看侧栏「设置」表单里预选的当前值。

### 调样式的位置

默认字号在 `font::DEFAULT_FONT_SIZE`（生效值经设置项夹取）；字体候选由
`font::installed_font_candidates()` 运行期实测，默认挑选顺序在 `font::resolve_font_family`；
行高若想更松，改 `font.rs` 里 `line_height` 的兜底倍数或在自然行框上加留白即可
（当前 13 px 字号 → 16 px 行高）。

三条约束在 `worker.rs` 里有注释说明：命令优先（输入不被输出拖累）、输出限时合并
（否则持续刷屏时帧节流检查永远轮不到）、无轮询空转（空闲终端零唤醒）。

## 多会话

- 左侧栏列出所有标签：标题取自当前聚焦格里前台程序的 OSC 0/2，没设置时用显示编号
  （关闭其他标签不会跳号；关掉最后一个标签后，新会话重新从「会话 1」开始，ADR-042）；
  已结束的标签用暗色显示。点一行切换过去，行尾 `✕` 关闭该标签。
- **手动重命名**（ADR-047）：右键会话行 → 「重命名」弹输入框（不切换标签），起的名字盖过
  OSC 标题与显示编号，只影响侧栏这一行（窗口标题仍跟前台程序）；留空确认恢复自动标题。
  名字随工作区落盘，重启后本地标签的名字保留（SSH 标签本就不持久化）。
- 顶栏右侧是 ⚙ 设置与 `?` 快捷键入口；底部固定一行「本地 │ WSL │ SSH」
  （WSL 仅 Windows，零发行版时隐藏），行尾是三点的主题色板（ADR-041）。WSL 入口点击时现查注册表并
  弹出选择模态（发行版名 + 家族/版本副行，默认置顶带「默认」标记）——单个发行版也
  经用户选定后再开会话。
- 关闭当前标签后激活它的邻居（`active_after_close`，有单元测试）；关掉最后一个会自动新开一个，
  保证窗口里始终有终端。
- **关闭二次确认**：经侧栏 ✕、⌘W、格内 ✕ 显式关闭时，若目标里有未结束的 SSH 会话
  （连接与远端程序将被断开）、备用屏上全屏程序在跑（vim/htop 等），或本地 shell 前台
  运行着子程序（pi、本地服务等，点关闭那一刻用 PTY 前台进程组探测），先弹确认浮层；
  已结束的会话与空闲本地 shell 直接关，正常结束的自动回收（本地格退出即收）不经确认。
- **本地格正常结束会自动关掉该格**（应用按固定节奏检查一次）；多格标签里只收这一格，
  焦点交给它的兄弟格，最后一格才收标签。**SSH 格在远端 shell 退出后不自动关**：SFTP 在
  shell 退出后仍可用（ADR-005），由用户手动关闭。连接失败一律**不关**：失败原因得留在
  屏幕上给你看。两条规则都有端到端验证。
- 快捷键：macOS ⌘T / ⌘W，其他平台 Ctrl+Shift+T / Ctrl+Shift+W，分别新建与关闭会话。
  多格标签里 ⌘W 先关聚焦格，只剩一格时才是关标签（ADR-014）。单独 Ctrl+T / Ctrl+W 是终端控制
  字符（^W 删词、^T 对调字符），必须留给前台程序；Ctrl+Shift 也是 Windows Terminal、
  GNOME Terminal、Konsole 的通行键位。判定挂在应用根元素上，靠按键事件从焦点元素向上
  冒泡到达；会话视图必须先放行这两个键（不转发也不拦截），否则会被编码成 ^T/^W 发给
  前台程序，应用层永远收不到。
- 拖拽排序：按住某一行拖动到目标行松开即可换位；被拖的标签保持选中，下标按
  `active_after_move` 跟随。落点按渲染帧写下的行 bounds 判定，所以拖到列表外会钳到首尾。
- 每个格是独立 worker：各自的 Shell、各自的滚动历史、各自的选区与模式。
- 界面骨架：**没有顶栏**（品牌、字体字号、状态文案都不常驻显示）——终端区域直接顶到窗口上缘；
  远端会话每格底栏常驻，按会话阶段显示状态、远端监控与结束原因，右端是 SFTP 与转发开关
  （开关钉死右缘，窄窗口下收缩裁剪的是左侧信息区，不把开关挤出去）；
  **本地默认 Shell 格有一条探针底栏**（ADR-028，修订 ADR-016 的「本地格不设底栏」）：
  与远端底栏同位置同款（30px、上边框），信息区留空，右端一枚「进程」开关，展开右侧
  停靠面板（进程树 + LISTEN 端口，开即采、关即停）；启动中、启动失败与终端不可写入
  仍在终端区域中央显示（启动失败附「Enter 关闭」），也不产生复制/剪贴板写入/打开链接
  这些操作回执；WSL 格无底栏（ADR-016）：终端区域直接顶到窗口下缘，网格多约一行；
  会话的身份信息在侧栏行里：第一行是前台程序标题（没有则用显示编号），第二行是来源标签。
- 回看标记：滚轮回看历史时，最左缘出现一个占满行高的饱和琥珀色竖块，锚在**滚动起始的那一行内容**上
  （往上滚 = 当时的视口首行，往下滚 = 当时的视口末行），之后跟着文字一起滚动，滚出视口即消失、
  回到实时视图重置（替代了原先顶栏的「回看 N / M 行」文字）。

## 主题（ADR-022）

- 入口在**侧栏底部动作行末尾**：只显示当前主题的三点色板（主题背景叠红/绿/蓝），
  不显示主题名；点击展开下拉（向上弹出，带滚动）。
  每项是「色板（主题背景叠红/绿/蓝三点）+ 主题名 + 当前项标记」。
- **点击即切换、下拉不收起**：点一项立即给整个界面换肤（终端网格 + 全部 UI 一起）
  并落盘（`settings.json` 的 `theme` 字段），连续点几项比对观感；收起只由点击
  下拉之外（遮罩）触发。不做悬停预览——整屏换肤跟手晃动太刺眼。
- **33 套内嵌主题、不支持自定义**：Default（One Dark 系，与界面底色同源）+ Ayu
  Dark/Light/Mirage、GitHub 九变体（Light/Dark 的默认、Legacy、Colorblind、High
  Contrast，外加 Dark Dimmed）、Catppuccin 四变体、TokyoNight 三变体、Rosé Pine
  三变体、Gruvbox Dark/Light、Everforest Dark/Light Med、Kanagawa Wave/Dragon、
  One Half Dark/Light、Nord、Dracula，编译期静态表（`theme/builtins.rs`）。
- **一套主题只给终端配色**（前景/背景/光标 + 16 ANSI 色），界面的几十个颜色全部由
  推导算法生成（`theme/derive.rs`）：背景分层与文字梯度按方案明暗方向插值，语义色取
  ANSI 红/黄/绿。Default 的界面 token 是手调基准（与历史观感逐值一致），其余主题全走
  推导；推导算法对 Default 的输出有基线测试守护，防止档位漂移。
- 切换**下一帧生效**，无需重放输出：终端网格存语义色，每帧快照时才按当前方案解析；
  会话经 `SessionCommand::SetTheme` 收到新方案的引用即可。颜色查询（OSC 4/10/11/12）
  按当前方案回答，光标用主题光标色填充，选区维持反相（任何主题下对比度天然成立）。
- **主题来源与许可**：Default 为本项目自研（One Dark 系）；其余 32 套取自公开主题集——
  Ayu 三变体（Dark/Light/Mirage）与 GitHub 九变体来自
  [terminalcolors.com](https://terminalcolors.com/themes/ayu/light/)，
  其余来自 [iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes)
  的 Windows Terminal 导出（集合 MIT 许可，各主题版权归其各自作者）；Catppuccin /
  Dracula / Nord / Gruvbox / Tokyo Night / Rosé Pine / Everforest / Kanagawa 的上游
  调色板均为各自项目的 MIT 许可发布。

## 会话输出日志（ADR-017）

- 开关在会话底栏「记录」按钮打开的「记录」模态里（ADR-017 修订：运行时开关，只作用于
  本格本会话，不写进任何设置或连接存储），模态里同时显示日志文件名、可交给系统程序
  外部打开；开启后该格的输出写入应用配置目录的 `logs/` 下（文件名 = 建格时间戳 + 来源标签）。
  本地会话不提供开关。
- **记录终端渲染后的行文本**：屏幕上看到什么，日志里就是什么——折行接续成逻辑行，
  `\r` 重绘只记最终状态（进度条收敛为一行），CJK/组合字符按模型还原；vim/htop 这类
  全屏程序的界面画在备用屏上，不进日志。纯文本，vim/cat 直接可读。
- **只记输出不记输入**：输入路径不接触日志；无回显的口令（ssh/sudo 密码提示）不落盘；
  敲过的命令经 TTY 回显会出现在日志里，与你在终端里看到的一致。
- 每次会话尝试（初次连接、每次重连）各写一对 `==== 会话开始/结束 时间戳 ====` 标记，
  正文夹在中间；会话收尾把仍留在屏幕上的行冲进日志。重连与同秒同目标的分屏共用
  同一文件（追加模式，靠标记区分）；运行时开关切换各落「记录开启 / 记录暂停」标记
  （暂停期间已滚出的行不回补，恢复后才滚出的内容随恢复后的转录落盘，ADR-044）。
- 分屏新格是独立会话：各有自己的开关与文件，新格默认未开启。
- 日志是尽力而为的旁路：文件打不开/写失败只停写并在侧栏亮「⚠ 日志」标记
  （持续到本格结束），绝不阻断或拖垮会话；无轮转、无上限，清理是用户的事
  （与 MobaXterm 口径一致）。

## 分屏（ADR-014）

- 二分嵌套：任意格可再分（左右并排 ⌘D / 上下堆叠 ⌘⇧D，非 macOS 是 Ctrl+Shift+D /
  Ctrl+Shift+Alt+D），每标签最多 8 格，布局不持久化（重启回到单格）。
- **新格的会话类型跟随原格**：SSH 格分屏用同一目标（含内存中的凭据）新开一条独立连接，
  本地格就是本地 shell——「远端看日志 + 敲命令」是主要用法。
- 每格自带网格（顶栏已去掉；底栏：远端格是状态底栏，本地默认 Shell 格是探针底栏，
  WSL 格无，见 ADR-016/028），格内 resize 走既有 canvas → PTY 链路；多格时每格右上角悬浮
  `✕ 关闭此格`（布局层叠加，不动会话视图本身）。
- 分割条 4px 命中区、1px 视觉线，拖动即时改比例，比例夹在 15%~85%；点击某格即聚焦它，
  ⌘W、R 重连、搜索条都作用于聚焦格。
- 布局与比例是纯逻辑（`panes` 的 `PaneTree`：分割、关闭、比例夹取、布局与分割条矩形），
  有独立单测；渲染装配按模态渲染的同一模式下沉到 `panes`，app 只留交互装配（ADR-007）。

## 终端内搜索（ADR-015）

- `⌘F`（非 macOS 是 Ctrl+Shift+F）打开底部搜索条，焦点进输入框；Esc 关闭并清高亮。
- 输入即增量搜索（向前），回车下一个、⇧回车上一个；`.* 正则` 开关默认关（字面匹配，
  元字符被转义），开着时按正则解释，编译失败在条上显示「正则无效」而不是静默无匹配。
- 大小写智能沿用 `alacritty_terminal` 的 `RegexSearch`：模式全小写时不区分大小写，
  含大写则区分。搜索范围是视口 + 全部滚动历史，但**单次匹配不跨行**（上游把行边界当
  输入结束处理），因此高亮至多一段。
- 命中后匹配行滚进视口（已在屏内则不动视口，避免逐字输入时来回跳），高亮以半透明琥珀色
  叠在文本之下，随后台进程的新输出一起重画。搜索在 worker 侧执行（历史只在 worker 里），
  UI 只发命令、收反馈与带高亮的画面帧。

## SSH 会话

- 入口固定在**左侧栏底部动作行**（「SSH」），打开**模态框**，默认是**已保存连接的列表**（ADR-048）：
  每行右侧是「连接」「编辑」「删除」三个文字按钮，**行本身不可点**（防误触连出去）；底栏「新建连接」
  进空白表单。Esc 或点空白处关闭。
- 编辑视图是单栏表单（名称 / 主机 / 端口 / 用户 + 认证信息 + 跳板 + 转发），底栏三个动作分开：
  `保存`（回车；落盘后回到列表）、`保存并连接`（先落盘成功再连，保存失败就不连，避免"以为存好了"）、
  `返回`（Esc；丢弃改动回列表）。连接与编辑不在同一个界面，按钮文案不随改动跳变。
- **名称**可选：起过名字的连接在列表里以名字为标题（下行仍显示 `user@host:port`），并成为连上后侧栏
  标签的初始名（ADR-047 的用户名字，重命名照常）；留空按 `user@host:port` 显示。名字不参与条目身份。
- **主机字段只填主机地址**；粘贴 `user@host:port`（含 `[::1]:2222`，即 `ssh` 的目标语法）时会
  **自动拆分**：用户名、端口分别填进「用户」「端口」两个字段。拆分发生在离开主机字段或提交时；
  **目标字段已有不同的值时报错让用户二选一，不静默取舍**——粘贴一次不用担心哪一份值被悄悄丢掉。
- 保存的连接在 `~/Library/Application Support/Zhimaterm/connections.json`
  （`ZHIMATERM_CONFIG_DIR` 可覆盖，测试靠它不碰真实配置）：
  - 只存名称、主机、端口、用户、认证信息引用（agent 开关、私钥路径）、agent 转发开关与转发规则，
    **口令与私钥口令不落盘**（ADR-002）。
  - **记住密码**（ADR-018，2026-10-29 修订：输入即保存）：表单里输入了密码并保存，密码就
    写入操作系统安全凭据存储（macOS 钥匙串 / Windows 凭据管理器 / Linux Secret Service），
    没有「记住密码」勾选框；`connections.json` 只存一个引用标记。凭据按**条目的随机 id**
    挂钥匙串（ADR-018 修订）：一条连接一条凭据，改主机/端口/用户不需要任何迁移，
    同身份的重复条目各有各的密码。钥匙串只在两个时机读取：**编辑视图里点密码框内的
    「显示」**主动查看（开关嵌在框内右缘；再点「隐藏」换回掩码），以及**连接确实需要
    密码时**（仅密码条目点「连接」或「保存并连接」、连接期自动应答）。点「编辑」载入
    不回填、不碰钥匙串——已记住的条目载入后，空的密码框显示一串星号示意「已存有密码」。
    已记住的条目保存时密码框留空就沿用已存的密码（**不会用空密码覆盖，也不会删除**）；
    删除凭据的唯一出口是忘掉这条连接。私钥口令不提供记住。
  - 只有密码认证且没记住的条目（列表里显示 `密码 · 需输入`）点「连接」后先弹一个密码输入框，输完即连，
    密码只用于本次连接。认证中途落到密码路而手头没有密码时，**连接期间在终端内现场询问**
    （「连接需要密码」卡，ADR-018 修订）：已存凭据先自动应答；答错重问，**连续三次全错按
    认证失败收尾**（防爆破）；临时密码只用于本次连接、不落盘；等待输入期间底栏显示
    「等待输入密码」，秒表停走、不占连接超时预算。跳板的询问带跳板身份——跳板口令
    不落钥匙串，也不会拿目标的已存密码去应答跳板。
  - 保存按条目 id 落盘：编辑原位替换、新建追加，同"用户@主机:端口"的重复条目允许并存
    （ADR-048 修订）；写入是临时文件 + rename，不会写坏半个文件。
  - 文件读不出来时进入"不可用"状态并在列表位置说明原因，这时**拒绝写入**，
    免得把读不出来的文件覆盖成空列表，把存过的连接真的弄丢。
- **认证信息叠加**（ADR-010）：agent、私钥文件、密码三者可同时提供，按
  **agent → 指定私钥 → 密码**的公开顺序尝试，全部失败时逐项报告原因（不做静默降级）：
  - 本地 `ssh-agent`：一个默认开启的开关（表单里可关，等价于 OpenSSH 的 `IdentityAgent none`：本次连接完全不使用 agent）。
    agent 的连接路径不做配置，靠系统约定自动发现（`SSH_AUTH_SOCK` / Pageant / OpenSSH 命名管道）；
    连不上时失败信息里会说明。概念图解见 [ssh-agent 图解](ssh-agent-explained.md)。
  - 私钥文件：右侧「选择…」开原生文件选择器（也可以手输路径，支持开头的 `~`）；
    同目录存在 `<私钥>.pub` 时会一并交给 libssh2。
  - 密码：**先试键盘交互再试 password**。很多服务器（走 PAM、要二次验证的）只提供
    keyboard-interactive，只试 password 会得到一句没头没脑的"认证失败"。
    两个方法各自失败时都会带原因一起报出来。
- 应用**不扫描 `~/.ssh/id_*`**，也不做默认密钥发现（ADR-002）：用了哪把钥匙始终由你指定。
- 凭据只随会话配置交给会话线程一次，认证一结束就就地覆写并释放（`Drop for SshAuth`），
  私钥路径与口令都不落盘（ADR-002）。
- 输入框组件（`src/ui/input/`）：
  - 三档状态：普通（暗边框）、悬停（边框提亮）、聚焦（强调色边框 + 字色提亮 + 光标），
    避免点上去像被禁用。
  - 完整编辑能力：单击定位、拖选（拖出框外自动滚动）、双击选词、三击选段、
    Shift+方向键扩选、⌘A 全选、⌘C/⌘X/⌘V 复制剪切粘贴、⌘Z/⌘⇧Z 撤销重做；
    ←/→ 按字素簇，词级跳转 macOS 是 Option、其他平台是 Ctrl，Home/End 到行首尾
    （多行按光标所在逻辑行），⌘↑/↓ 到全文首尾；多行框里 ↑/↓ 按视觉行移动，带 goal column。
  - 键位来自 `ui::input::bindings()`（main 随应用键位一起注册）：输入框获得焦点时按键被
    输入框消费；焦点在终端等其他位置时，没有处理器接收的按键照常回落给前台程序
    （↑ 仍是历史命令、⌘V 仍是终端粘贴）。
  - 占位文本只在内容为空时出现，光标停在最左边，不会被占位推走。
  - 粘贴：macOS 是 ⌘V，其他平台是 Ctrl+V。单行框的清洗规则与旧实现一致：换行丢掉
    （口令尾部不能静默多出空格）、制表符变空格、其余控制字符丢掉；多行框原样保留。
    这条规则和终端那边刻意不同：终端里 Ctrl+V 是控制字符要留给前台程序，所以那边用 Ctrl+Shift+V。
  - 内容超宽时水平滚动、多行框按视口宽软换行并垂直滚动，滚动指示条在聚焦/拖选/刚滚动过时显示。
  - 掩码（密码）下每个字符按 UTF-8 字节长度换成同长掩码字符（密文与索引空间仍是明文），
    复制/剪切不写剪贴板。
- 主机密钥：写在**本应用受管**的 known_hosts（macOS 是 `~/Library/Application Support/Zhimaterm/known_hosts`），
  不读写用户的 `~/.ssh/known_hosts`。未知主机先在终端区域弹出确认浮层，显示算法与
  `SHA256:` 指纹；已记录主机的指纹变化同样弹确认浮层（警示文案更强、按钮为
  「信任新密钥并连接」），用户显式确认后按主机名+端口替换记录——绝不静默替换。

### 端口转发（本地与远程，ADR-011）

- 规则在连接表单里编辑、随连接持久化：**本地转发**填本地端口 + 目标主机/端口；
  **远程转发**填远端端口 + 目标。类型与监听地址用 chip 切换——
  本地监听默认只绑 `127.0.0.1`，绑 `0.0.0.0`（对外网开放）必须显式切换。
- 规则在连接建立时一次性搭好：本地监听的 accept 在每规则一条专用线程（阻塞 accept，
  新连接唤醒 pump）；远程监听的 `Listener` 由 pump 持有、每轮非阻塞 accept。
- 数据桥接在 pump 内逐轮有限量搬运：通道侧每轮无条件读（与监控通道同模式），
  本地 socket 进 poll 等待集合。单条连接的失败只丢该连接；**单条规则失败（端口占用、
  远端拒绝）只标红该规则，不影响会话与其他规则**，实际绑定端口以服务端/系统返回为准。
- 会话底栏右侧的「转发」按钮打开状态浮层：每条规则的监听端口与活跃连接数、失败原因。
- 远端 shell 退出后转发随会话一起结束；重连按配置自动重建（失败的规则照常标红）。
- 动态 SOCKS 与运行中增删规则已实现（ADR-038）：浮层内可增删 L/R/D 规则，
  监听立即生效，勾选「同时保存到连接」会回写连接配置。

### agent 转发（ADR-012）

- 会话级开关（默认关）：远端程序（`git`、`ssh` 跳板）的签名请求经 SSH 连接传回
  **本机 agent** 完成，私钥不离开本机、不用往服务器拷钥匙。
- 请求在 shell 启动前发出（sshd 要求：环境变量得在 shell 前布置好）；
  libssh2 收到服务端反向打开的 `auth-agent@openssh.com` 通道后由我们的回调接管，
  与本地 agent socket 双向桥接（`transport/agent_forward.rs`，含最小 FFI）。
- 开启前提：本次连接能用本地 agent（远端要访问的就是它）；默认关是安全取舍——
  登录期间远端 root 理论上可借用转发通道请求签名，只在信任的服务器上开。
- Windows 首版显式拒绝并如实报错（命名管道无非阻塞模式，双线程桥接与 Windows
  验收同期补齐，见 ADR-012）。
- 端到端验证：真实 sshd 上远端 `ssh-add -l` 列出本机 agent 的钥匙（门控用例）。

### 连接保持与自动重连（ADR-013）

- **keepalive 心跳默认开**：30 秒一拍（libssh2 的 want-reply 模式），连续 3 个间隔
  没有任何入向数据判定连接死亡——约 90 秒内发现断线，而不是等 TCP 自己超时。
  实现上等待预算多了一档"距下次心跳的剩余时间"，空闲会话因此每 30 秒醒一次（心跳语义本身）。
- **断线自动重连**：只对**认证成功过**的会话生效（连接/认证失败不自动重试——
  错误口令反复撞服务器会触发防爆破），且只认**意外断线**（socket 断开、keepalive
  超时、传输僵死）——用户主动 `exit` 或关闭会停在结束态等 R / Enter，不会自己爬起来。
  指数退避 1/2/4/8/16 秒、最多 5 次；
  底栏显示「Ns 后自动重连（第 x/5 次）」，**Esc 取消**，R 立即手动重连（并清零次数）。
- 重连沿用原地重连机制（代数隔离，旧连接的迟到事件不污染新会话）：终端是新 PTY、
  画面清空，转发规则与 agent 转发按配置自动重建。

- 侧栏会话行的第二行是来源标签：远端显示 `user@host:port`，本地显示 `LOCAL`，
  WSL 格显示 `WSL · <发行版名>`：远端输出不可信，界面上要能一眼区分。
- 远端 PTY 的尺寸与像素尺寸随窗口变化同步（`request_pty` + `request_pty_size`），
  所以远端 `stty size` 与图片/字体比例的判断都拿到真实值。
- 端到端验证需要一台 sshd：见 [runbooks/ssh-e2e](../runbooks/ssh-e2e.md)。

### SFTP（与 shell 共用一条连接）

- SFTP subsystem 与 shell channel 走**同一个 `ssh2::Session`**，全部 libssh2 调用都归
  pump 线程串行执行（ADR-001/005）。UI 拿到的是可克隆的 `SftpHandle`：连接成功后随
  `SftpReady` 控制事件交给视图，命令直达 pump，结果经 oneshot 通道返回。
- 已支持：realpath（定位登录目录）、readdir（列出目录，`.`/`..` 由客户端自己给导航语义）、
  stat、mkdir、rmdir（仅空目录）、unlink（文件与符号链接，不跟随链接）、rename（目标
  已存在即报错，不静默覆盖——ADR-002）。
- **生命周期解耦**（ADR-005）：远端 shell 退出只结束 shell，连接与 SFTP 继续活着；
  会话在用户关闭、socket 断开，或 SFTP 句柄全部被丢弃时才结束。会话关闭后句柄立即
  失效，调用报明确错误而不是挂起。
- pump 每轮先照看 shell 读写，再处理至多 8 条 SFTP 命令；单条目录命令在 5 秒上限内
  同步完成（一次网络往返量级），慢网络下最坏占用 pump 这么久，期间 shell 交互同级延迟。
- **传输引擎**（ADR-005 阶段 2）：
  - 上传：写远端同目录隐藏临时文件（分块推进，每轮 ≤256 KiB）→ fsync → rename 提交。
    新文件 rename 原子提交；确认覆盖的服务端拒绝覆盖 rename 时（含 OpenSSH v3 的
    绑定限制，见 ADR-002）回退为直接写入目标。
  - 下载：写本地同目录临时文件 → fsync → 平台原子替换。
  - 递归删除：客户端深度优先遍历，文件与符号链接 unlink（不跟随链接），目录从最深
    往上 rmdir；每轮至多 8 个条目，不独占会话。
  - 目录上传/下载（树形任务）：本地/远端深度优先展开，逐级建目录；每个文件独立走
    临时文件 + rename 提交，与单文件同规则；进度按字节报告，可取消（当前文件收尾
    后停止并清理半成品）。目录上传向已有远端目录合并（同名文件替换）。
  - 三类都是任务型操作：进度事件（可合并）+ 终态事件（保证送达）+ 取消；取消在当前
    分块后生效并清理临时文件（清理失败时终态带路径）。任务连续 2 秒无法推进判定
    连接僵死，强制关闭会话并让全部任务进入失败终态。
  - 传输期间 shell 输入输出照常调度：任务每轮只推进一步，等 socket 时 pump 等待压到
    1 ms 保吞吐。
  - **SFTP 面板**（ADR-005 阶段 3，`src/views/sftp_panel.rs`）：SSH 会话底栏右侧的 `SFTP` 按钮
  开关，展开后终端右侧多一列（300 px）：
  - 目录浏览：打开即定位登录目录；↑ 上级 / ↻ 刷新；**单击选中**（目录与文件同等，
    操作条动作对两者可用），**双击目录进入**；目录在前、按名排序，`symlink` 有独立标识。
  - 操作：上传（**原生文件/文件夹选择器**，选文件单传、选文件夹整棵上传）、下载
    （文件走系统「存储为」对话框；目录选目标位置后整棵下载）、重命名（预填当前名）、
    删除、新建目录。
  - 确认规则按 ADR-002：目标已存在的上传/下载先弹覆盖确认（目录上传为合并语义，
    同名文件将被替换）；下载的目的地由原生对话框选定，目标不存在时选完即开始，不再追问；
    目录删除先试空目录 `rmdir`，非空报错后弹**递归删除确认**
    （红字标明不可恢复）；重命名不覆盖。
  - 进行中任务区（目录列表与状态行之间）：每条任务两行——任务描述（动作与文件名）与
    「取消」在上，进度文本在下（树传输经进度事件带出正在处理的文件名，进度按字节/条目
    格式化，总量未知时只显示已完成量）。传输完成自动刷新目录列表；成功操作不弹提示——
    列表刷新后结果肉眼可见，错误红色显示在面板内。
  - 已结束的操作落**操作记录**：入口在会话底栏右端的「历史」按钮，展开全屏模态，与
    SFTP 面板解耦（不开面板也能看，SSH 会话即显示）；有未读的新操作时按钮高亮，打开
    模态即清除。每条记录单行——状态符号、终态文案与结束时刻，长文案按弹层宽度换行
    不做省略截断；只存在内存里、最多 200 条，关闭会话即清空（Esc 或点空白处关闭）。
    会话日志的开关与外部打开在「历史」旁的「记录」模态（见「会话输出日志」一节）。
    确认弹窗正文同样按宽度换行，长路径不被截断。
  - 面板实体自持句柄与任务事件循环；`TerminalView` 只挂载与开关，不接触 SFTP 状态。

## 超链接

- OSC 8 链接由核心解析并挂在单元格上，我们在快照里按段带上 uri（链接会把行切段，跨链接不合并）。
- 纯文本 URL 同样可点（hints）：快照构建时按行识别 scheme 为 http/https/ftp 的 URL，
  走与 OSC 8 完全相同的交互。`file://` 与裸域名不识别（安全与误报考量，见 ADR-002）；
  尾部句子标点剥除、闭括号保留配对；折行的长 URL 各行各自成链（单行识别）。
  显式 OSC 8 标记优先于文本识别。
- 外观：链接平时不改变字形（核心也不给链接加下划线），**指针悬停时才加下划线**并切换为手型指针。
- 打开：⌘（macOS）/ Ctrl（其他平台）+ 点击。这一下不再交给终端——既不选区也不做鼠标上报，
  避免与程序自己的点击处理打架。

## 鼠标与选区

- 单击精确选区、**双击按词**、**三击按行**（连击次数用平台给出的值，跟随系统双击速度设置），
  **Alt 拖动**是矩形块选。语义展开由核心的 `SelectionType` 完成，高亮与复制共用同一份范围。
- 程序打开鼠标上报（`CSI ?1000/1002/1003 h`）后，同一批手势改走协议上报：SGR（`1006`）用
  `CSI < b ; x ; y M/m`，传统编码用 `CSI M` + 三个偏移字节，`1005` 时坐标按 UTF-8 码点发送，
  滚轮用 64/65（横向 66/67）。程序接管期间不再画本地选区。
- `MOUSE_DRAG` 只上报按住时的移动，`MOUSE_MOTION` 连悬停移动也上报；UI 一直转发移动事件，
  是否上报由 worker 按模式决定。

## 输入法

- 终端没有可编辑缓冲区，因此组合文本**只在界面上可见**（画在光标格上，带下划线，不另占一行），
  提交后按原样写给前台程序；不做 bracketed paste 包裹，因为这是打字不是粘贴。
- 候选窗位置来自终端光标所在的格（`bounds_for_range`）。
- 组合期间按键由平台交给输入法，不会同时走按键编码；非输入法环境下普通按键路径不变
  （见 `gpui-pre-macos` 的 `is_composing` / `is_ime_input_source_active` 判定）。

## 终端核心事件

终端核心（`alacritty_terminal`）只处理语义，跨到 PTY 或 UI 的动作通过 `EventListener` 交出来。
`TerminalModel` 用 `TermRequestProxy` 把事件收进队列，worker 每轮排空一次：

- `PtyWrite`：终端查询的应答（DA1 `CSI c`、DSR 5/6、DECRQM、键盘模式、`CSI 18t`），
  由 worker 按前台程序输出的顺序写回 PTY。不写回会让程序降级功能或等在超时上。
- `Title`/`ResetTitle`：OSC 0/2 标题 → 控制事件 → 窗口标题与侧栏会话行；空标题按核心语义回到默认标题。
- `Bell`：BEL → 控制事件 → 该会话的侧栏行点亮「🔔 响铃」标记（切到该标签或点进该格即清除）；
  底栏不显示响铃——底栏是常驻信息区，不是通知区。

- `ClipboardStore`（OSC 52 写剪贴板）按 ADR-002 的策略放行：程序可以写本地剪贴板，
  读取请求在核心配置层就被拒绝。
- `ColorRequest`：颜色查询（OSC 4/10/11/12）按索引回**有效颜色**——程序改写过的优先，
  否则用内置调色板（0..256 索引色、256 前景、257 背景、258 光标、259..267 dim 系列）。
- `TextAreaSizeRequest`：`CSI 14t` 用 UI 上报的格子像素尺寸回答；PTY 的像素尺寸也用同一份数据。
- `MouseCursorDirty`：程序开关鼠标上报时切换指针形状（接管 → 箭头，交还 → 文本光标）。
