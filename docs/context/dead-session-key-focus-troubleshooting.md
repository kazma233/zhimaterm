# 排障记录：会话结束后 Enter/Esc/R 无反应——blur 的落点问题

状态：已定位并修复（2026-11，焦点不变量见 [GLOSSARY「会话视图归约」](../../GLOSSARY.md)）。
记录排查路径与 gpui 焦点派发的关键事实，供以后处理「按键完全无反应」类问题时参考。

## 现象

SSH 会话里输入 `exit` 退出后，按 Enter 不关格、Esc 不取消重连、R 不重连——
死会话裸键全部失灵；先点击一下终端网格，三键才恢复正常。

## 根因：blur 把焦点落到「None」，而 gpui 无焦点时按键派发不经过任何应用层节点

排查链（自症状向上）：

1. 点击后三键恢复 → keydown 管道与应用层根节点的死会话裁决（`app/keys.rs`）
   本身是好的；坏的只是「焦点为空」这一档。
2. 会话结束（`Exited`/`Failed`）历来会置 `blur_pending`，渲染时机执行
   `window.blur(cx)`——意图正确：焦点留在输入网格会继续喂 IME/文本管道
   （keydown 与 `replace_text_in_range` 双管道并行，R 会双发，Esc/Enter 在
   文本管道被吞）。
3. 但 `window.blur` 是 `self.focus = None`，而 gpui 的按键派发在没有焦点时
   从**窗口合成根节点**起且只含它自己（`focus_node_id_in_rendered_frame(None)`
   回落到 `root_node_id()`）：应用根 div 的 `on_key_down` 是窗口根的**后代**，
   不在派发路径上，一个键都收不到。应用根注释「应用根总是位于焦点路径上」
   的断言在无焦点时不成立。

一句话：blur 的方向对（离开输入管道），落点错（落到无焦点 = 把按键一起扔掉）。

## 修复

结束态的一次性焦点动作从「blur 到无焦点」改为「focus 到格内**非输入锚点**」：
`TerminalView` 持有第二个 FocusHandle，渲染成视图根里一个**零尺寸、不参与
命中**的锚点元素；`take_focus_action` 产出 `OffGrid`，渲染时机执行
`window.focus(&锚点)`。效果：

- 派发路径恢复 `[锚点 → 视图根 → 应用根]`，R/Esc/Enter 直达死会话裁决，
  无需先点击；
- 锚点不是文本输入处理者，没有 IME/文本管道，R 不双发（blur 的初衷保住）；
- 点击网格、重连成功后焦点照旧交回输入网格，既有行为不变。

锚点必须零尺寸：gpui 里 `track_focus` 的元素会在**鼠标按下命中自己的
hitbox 时自动聚焦并阻止祖先抢焦**（`div.rs` 的鼠标按下监听）——第一版把
锚点挂在包裹网格的容器上，点击终端全被容器抢焦，输入网格再也拿不到焦点，
终端打不了字（当日即改）。锚点只需要存在于派发树里（焦点路径的起点），
不需要可见可点。

## 同主题后续：重连失败后 R 要先点击才有效

锚点修复验收时发现第二层：R 重连发起（焦点预定交回网格）与连接失败
（预定离网格）可能**同帧到达**——重连在 keydown 处理器里同步置
`terminal_focus_pending`，认证拒绝几百毫秒内 Failed 就到，两个一次性
焦点标志同挂。消费优先级 Terminal > OffGrid，焦点被交给**死网格**
（文本输入处理者——平台继续把按键路由进残留的输入处理器，R 蒸发），
`blur_pending` 永远留置；点击网格重新聚焦后平台路由状态复位，R 恢复。

修复：结束态（`enter_ended`）作废**全部**一次性聚焦标志，包括
「交回网格」——连接已死，那条指令已失效。失败后焦点必然落锚点
（非输入节点），R 经 keydown 直达，无需点击。锁定测试：
`failed_reconnect_does_not_hand_focus_back_to_the_grid`。

## 可复用的诊断方法

- 「按键完全无反应」先问焦点在哪：gpui 的 `on_key_down` 只在**焦点派发
  路径**上触发；焦点为 None 时派发路径只有窗口合成根，任何应用层监听都
  收不到。让某个真实元素持焦（且它不是文本输入处理者）是最小修复面。
- 「能点不能打字」查有没有新加的 `track_focus` 抢走点击聚焦：命中链上
  更深的 focusable 元素先冒泡、聚焦自己并 `prevent_default`，网格的
  句柄就永远轮不到。落焦锚点类元素一律零尺寸。
- 改焦点行为必须真机验收「按一下」级别的交互——合成输入进不了 gpui 窗口，
  无头测试只能锁「焦点落点」，锁不了「派发送达」与「点击聚焦归属」。本条
  验收步骤在 [人工验收清单](manual-acceptance.md)。
