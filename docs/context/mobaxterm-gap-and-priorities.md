# 与 MobaXterm 的能力差距与功能优先级

状态:P0 五项已全部落地(2026-10-15;1-3 见 ADR-010~013,4-5 见 ADR-014/015;认证模型由互斥三选一改为素材叠加,SOCKS 与动态增删转发规则后置)。**P1 已清空(2026-10-16)**:6-7 落地(ADR-017/018),8/9/11 决定不做,10 跳板机落地(ADR-020),乱码排查作为插入项修复完成(ADR-019)。**2026-10-21 批次已落地**:P2 #18(本地 Shell 选项,ADR-036)、#20(布局持久化,ADR-037)、SOCKS 动态转发与运行中增删规则(ADR-038)、滚动历史上限(ADR-035)、本地格重启恢复工作目录与全彩回滚(ADR-039/040);未落地的项见 `todo.md`。本文保留完整对比与排序依据。

对比基线:MobaXterm(成熟 SSH/SFTP 客户端)的常用能力,对照 zhimaterm 当前实现(功能行为说明 features.md 所述 + 源码确认)。表内「现状」随落地同步更新,不再是初版快照。

## 1. 现状基线

zhimaterm 已具备:多会话侧栏、本地 Shell 与 SSH 交互 Shell、完整 VT/ANSI(256 色/TrueColor、CJK/Emoji、鼠标协议、OSC 8 超链接、IME、选区、bracketed paste)、SSH 认证(agent/私钥/密码 kbd-interactive,素材叠加)、应用受管 known_hosts 与指纹校验、共连接 SFTP(浏览/增删改名/上传下载/目录树/递归删除,原子提交与覆盖确认)、传输任务面板与历史、远端资源监控底栏(CPU/内存/磁盘/网速,超出多数同类)、端口转发(ADR-010/011)、agent 转发(ADR-012)、keepalive 与断线自动重连(ADR-013)、分屏(ADR-014)、终端内搜索(ADR-015)、会话输出日志(ADR-017)、记住密码(ADR-018)、SSH 会话下发客户端 LANG 及底栏状态角标(ADR-019)、跳板机/ProxyJump 单级(ADR-020)、外观设置(字体/字号)、保存连接。

终端核心与 SFTP 传输正确性已扎实;差距集中在五块:SSH 协议层高级特性、文件管理交互体验、终端生产力功能、凭据与自动化、协议广度。

## 2. 差距分组

### 2.1 SSH 连接能力(缺口最大)

| 能力 | MobaXterm | zhimaterm 现状 |
|---|---|---|
| 端口转发/隧道(本地/远程/SOCKS 动态) | 有,图形化配置 | 本地/远程已实现(ADR-010/011);SOCKS 动态与运行中增删已实现(ADR-038) |
| SSH agent 转发 | 有 | 已实现(ADR-012) |
| 跳板机 ProxyJump / 级联连接 | 有 | 单级已实现(ADR-020,回环桥经 direct-tcpip);多级链式暂不做 |
| keepalive 心跳 + 断线自动重连 | 有 | 已实现(ADR-013) |
| X11 转发 | 有(内置 X server) | 无 |
| `~/.ssh/config` 别名兼容 | 有 | 有意不做(ADR-002 边界),列为已知取舍 |

注:X11 只做转发本身(配合 XQuartz 等),不内嵌 X server。

### 2.2 文件传输 / SFTP 体验

- 双栏文件管理器(远端 + 本地并排、拖拽互传):不做(2026-10-16,见 §3 P3);现为单侧远端面板 + 系统选择器,本地侧不可见。
- 拖放上传(文件拖进窗口即上传):不做(2026-10-16,见 §3 P3)。
- 右键用本地编辑器编辑远端文件(保存自动回传):不做(2026-10-16,见 §3 P3)。
- chmod/属主编辑:stat 只读展示。
- Zmodem(rz/sz):无;对方未开 SFTP 子系统时的唯一通路,中文运维场景常见。
- 断点续传、限速、多任务并行:无(断点续传是需求规格 §6 明确的首版取舍)。

### 2.3 终端生产力功能

- 分屏(split panes):已实现(ADR-014,标签内二分嵌套,每格独立会话)。
- 终端内搜索(搜滚动历史):已实现(ADR-015,⌘F 搜索条、大小写智能、正则开关)。
- 会话输出日志(滚动写入文件/带时间戳):已实现(ADR-017,只记输出;开关为会话内运行时开关,2026-10-24 修订)。
- 配色方案/主题切换:已实现(ADR-022,2026-10-17;内置主题含 Ayu/GitHub 全系列,外观设置持久化)。背景透明未立项。
- 字符编码切换(GBK/GB18030 老设备):UTF-8 only。
- 会话手动重命名:已实现(ADR-047,2026-10-27,右键会话行重命名、随工作区落盘);连接分组文件夹未立项,保存的连接为平铺列表。

### 2.4 凭据与自动化

- 记住密码(需求规格 §5 规划"写入 OS 安全凭据存储"):已实现(ADR-018,OS keychain;口令明文仍不进配置文件,ADR-002 边界不变)。
- SSH 密钥生成/管理器:无。
- 宏/命令片段/登录后自动执行命令:不做(2026-10-16,见 §3 P3)。
- 窗口/标签布局持久化(需求规格 §7):已实现(ADR-037,只记本地格含 WSL,SSH 不持久化)。
- 本地会话可选 Shell/工作目录:已实现(ADR-036);初始尺寸明确不做(分屏模型下无落点)。
- 快捷键自定义:硬编码于 `input::app_key_bindings`;应用单窗口,无多窗口/标签拖出。

### 2.5 协议广度(MobaXterm 工具箱型)

Telnet、FTP、SFTP 直连、串口、RDP、VNC、XDMCP、Mosh、网络工具(ping/traceroute/WakeOnLan)。按 zhimaterm 定位(开发者终端)做减法,见 §4。

## 3. 功能点优先级(按常用程度排序)

排序依据:目标用户(开发者、中文环境)的使用频率 × 场景广度。"人群集中"指对需要的人接近 100% 频率、但对人群比例较低。

### P0 — 广谱日常,几乎每天都会碰到

| # | 功能 | 为什么排这里 |
|---|---|---|
| 1 | 端口转发(本地/远程/SOCKS) ✅(ADR-011) | 连数据库、远端 Web 服务、内网代理,开发者日常;SSH 客户端仅次于"连上去"的能力。复用现有 pump 多路复用架构加 channel 类型即可,ADR-001/005 边界不动 |
| 2 | keepalive 心跳 + 断线自动重连 ✅(ADR-013) | 网络波动下会话存活,体验型刚需;已有手动 R 重连,补心跳与自动触发 |
| 3 | SSH agent 转发 ✅(ADR-012) | 跳机器 git push/pull 的前提,开发者高频 |
| 4 | 分屏 ✅(ADR-014) | 看日志 + 敲命令同屏是最常见布局诉求 |
| 5 | 终端内搜索 ✅(ADR-015) | 翻滚动历史查日志,日常高频 |

### P3 — 范围决策/明确不做

- 远端文件用本地编辑器编辑(P1 #8,2026-10-16 决定不做):设计盘点后取舍——SSH 会话内
  vim 等终端编辑器已覆盖该场景,不值得为它引入外部编辑器进程、本地副本管理、保存监控
  回传与远端权限回写整条链路。
- 命令片段/登录后自动执行(P1 #9,2026-10-16 决定不做):取舍结论如上,无额外背景记录。
- SFTP 双栏与拖放(P1 #11,2026-10-16 决定不做):取舍结论如上,无额外背景记录。
- Telnet、串口:运维场景仍有需求,作为决策项记录(做/不做都写明),不沉默缺失。
- RDP/VNC/XDMCP/网络工具箱(ping 等):不做,zhimaterm 定位开发者终端。
- 内嵌 X server:不做,只做 X11 转发。
- Mosh:暂不做。
- `~/.ssh/config` 兼容:维持 ADR-002 现有边界,已知取舍。
